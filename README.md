# 🐻 HoneyBear VPN (Ханибир)

Удобное и простое VPN приложение для Windows. Главная фишка — умное раздельное туннелирование: вы сами выбираете, какие приложения и сайты пускать через VPN, а что оставлять напрямую через родной интернет на максимальной скорости.

## ✨ Основные возможности

- 🔀 **Раздельное туннелирование (Split Tunneling)** — направляйте через VPN только нужные программы (Discord, Telegram, браузеры) или пользуйтесь готовыми списками.
- ⚡ **Отборная Hysteria** — отборная Hysteria (Hysteria 2) на мощном ядре sing-box: максимальная скорость соединения, минимальный пинг и стабильный обход любых блокировок.
- 📋 **Удобное добавление серверов** — вставка ссылок и ключей в один клик прямо из буфера обмена.
- 🛡️ **Режим DNS** — встроенный DNS и надежный обход блокировок.
- 🔄 **Безопасное автообновление** — проверка целостности SHA-256 и обновление в один клик.
